# Livestreaming Platform — Technology Stack & Architecture

## 1. Tổng quan

Platform livestream sử dụng các stack chính:

| Thành phần | Công nghệ | Vai trò |
|---|---|---|
| Frontend | ReactJS + Vite | Web application |
| UI | Tailwind CSS | Giao diện |
| Backend | Java 17 + Spring Boot | Business logic + API |
| Database | PostgreSQL / MySQL | Persistent data + metadata |
| Cache / Realtime | Redis | Viewer count, balance cache, realtime state |
| Event Streaming | Apache Kafka | Event-driven architecture |
| Realtime | WebSocket | Chat, gift, reaction, notification |
| Media Server | LiveKit / WebRTC | Livestream realtime |
| Stream Ingest | RTMP | Nhận stream từ OBS/camera |
| Playback | WebRTC / HLS / LL-HLS | Phát livestream |
| File Storage | Server Local Disk | Video, recording, image, document |
| Reverse Proxy | Nginx | HTTPS, routing, static files |
| Payment | Ví điện tử tại Việt Nam / Stripe | Nạp tiền |
| Monitoring | Prometheus + Grafana | Monitoring |
| Logging | Loki / OpenSearch | Log hệ thống |

# 7. File API

Spring Boot cung cấp API để đọc file.

Ví dụ:

```text
GET /api/files/{fileId}
```

Backend:

```text
fileId
   ↓
Database
   ↓
file_path
   ↓
Local Disk
   ↓
Response file
```

Ví dụ:

```text
GET /api/files/12345
```

Database:

```text
id = 12345
path = /storage/videos/10001/video-123.mp4
mime_type = video/mp4
```

Spring Boot đọc file và trả về:

```http
Content-Type: video/mp4
```

Browser có thể phát trực tiếp.

# 12. Redis

Redis dùng cho dữ liệu realtime và cache.

## Viewer Count

```text
stream:123:viewers = 48291
```

Khi user vào:

```text
INCR stream:123:viewers
```

Khi user rời:

```text
DECR stream:123:viewers
```

Không update MySQL/PostgreSQL mỗi lần viewer join/leave.

---

## Wallet Cache

Có thể cache:

```text
wallet:user:10001:balance
```

Tuy nhiên **database vẫn là nguồn dữ liệu chính cho số dư**.

Redis không được coi là nguồn tiền chính.

## Stripe

Flow tương tự:

```text
React
  │
  ▼
Spring Boot
  │
  ▼
Stripe
  │
  ▼
Payment
  │
  ▼
Webhook
  │
  ▼
Spring Boot
  │
  ▼
Wallet Transaction
```

### Quy tắc xác nhận nạp tiền

Sau khi payment provider xác nhận thành công:

```text
Payment SUCCESS
       ↓
Create Wallet Transaction
       ↓
Increase Wallet Balance
       ↓
Publish Kafka Event
       ↓
Notify User
```

Frontend có thể polling hoặc nhận WebSocket notification.

Nếu yêu cầu UX:

```text
Payment Success
      ↓
~5 seconds
      ↓
Balance updated / confirmed
```

**Không nên dùng delay 5 giây để xác định thanh toán thành công.**

5 giây chỉ nên dùng cho UI/UX sau khi webhook/provider đã xác nhận thành công.

# 22. Lưu ý khi sử dụng Local Disk

Local storage phù hợp với MVP hoặc hệ thống chạy trên một server.

Cần có:

- Disk monitoring
- Backup
- RAID nếu cần
- File permission
- Quota
- Cleanup
- Disk usage monitoring
- Backup database
- Backup video
- Recovery strategy

Nếu hệ thống sau này chạy nhiều media server/backend server, nên chuyển sang object storage:

```text
S3
MinIO
Cloudflare R2
AWS S3
```

Nhưng kiến trúc hiện tại vẫn có thể bắt đầu bằng local disk.
